# Migration lint baseline (OPS-008, DEP-012, TEST-061).
#
# The findings of migrations 0001-0087, which shipped in v0.2.0-alpha.1,
# before the lint existed. They are applied on real databases and the runner
# verifies the checksum of every applied file, so they cannot change. All of
# them first shipped together, so a release installation applies them to a
# new, empty database; each entry says why the finding was also acceptable
# for a database upgraded file by file. This list is history only:
# a new migration never gets an entry here. It avoids the finding, or
# carries the marker that allows it (CONTRIBUTING.md, "Database
# migrations"). TestMigrationLint (tests/contract) fails on a finding without
# an entry, on an entry without a finding, and on an entry for a file after
# 0087_restore_marker.sql. internal/storage/migrationlint.go defines the rules.
#
# Plain CREATE INDEX: CREATE INDEX CONCURRENTLY needs a no-transaction
# migration, which the runner only supports since 0.2.0-alpha.6. A plain
# build holds SHARE on its table (writes wait, reads continue) until the
# migration commits; since alpha.6 it no longer queues behind long queries
# (lock_timeout) and is retried instead.
#
# <file> <rule> <subject> <reason>
